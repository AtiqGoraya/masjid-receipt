تمام رسیدوں کا ریکارڈ

حذف شدہ رسیدیں شیٹ میں محفوظ رہتی ہیں لیکن یہاں چھپا دی جاتی ہیں اور ان کا نمبر دوبارہ استعمال نہیں ہوتا۔

رسید نمبر سٹیٹس عطیہ دہندہ مد / فنڈ رقم (Rs) فوٹر (تاریخ و وقت) عمل

آف لائن قطار (IndexedDB) اور دو ڈیوائس سنک ٹیسٹ

آف لائن بننے والی رسیدوں پر "عارضی نمبر" آتا ہے۔ انٹرنیٹ بحال ہونے پر سرور offline_created_at اور device_id کی ترتیب سے حتمی نمبر دیتا ہے۔

1. مکمل CSV بیک اپ ڈاؤن لوڈ اور خودکار رات 2 بجے بیک اپ

CSV فائل میں اردو کے لیے UTF-8 BOM شامل ہے، فارمولا انجیکشن (= + - @) سے محفوظ ہے، اور اس میں پورا ای میل کبھی شامل نہیں ہوتا (صرف 5 حروف کا کالم "بنانے والا" ہوتا ہے)۔

2. پرانی ایپ کے ڈیٹا کی منتقلی (Old Data Migration)

کسی بھی تبدیلی سے پہلے پرانی سنگل فائل ایپ کے ڈیٹا کو بیک اپ کے طور پر محفوظ کیا جاتا ہے، رسیدوں کی تعداد دکھائی جاتی ہے، اور آپ کی واضح منظوری کے بغیر کچھ بھی امپورٹ یا حذف نہیں کیا جاتا۔

3. بیک اپ بحال کریں (Restore CSV / Backup Sheet)

ری اسٹور کے لیے رائٹر پاسورڈ سیشن ضروری ہے۔ ہر قطار کی جانچ کی جاتی ہے (رسید نمبر موجود ہو، رقم درست عدد ہو، اور تاریخ درست ہو)۔ منظور اور مسترد قطاروں کی تعداد دیکھنے کے بعد ہی تصدیق کریں۔

⚡ گوگل شیٹ ایکسٹینشن (Apps Script) — درست Code.gs کوڈ (بغیر کسی Syntax Error کے)

⚠️ اہم وضاحت: Code.gs میں صرف جاوا اسکرپٹ کوڈ آتا ہے جس کی پہلی لائن /** @OnlyCurrentDoc */ ہے۔ کینوس کے Code ٹیب والا <!DOCTYPE html> کوڈ ہرگز Code.gs میں پیسٹ نہ کیجیے ورنہ SyntaxError: Unexpected token '<' آتا ہے۔

2. Apps Script ایڈیٹر کھولیں ↗
  1. اوپر پیلے بٹن "📋 1. مکمل Code.gs کاپی کریں" پر کلک کیجیے (یا نیچے ڈبے میں کلک کر کے Ctrl+A اور Ctrl+C دبائیے)۔
  2. اپنے Apps Script ایڈیٹر میں Code.gs کے اندر پہلے سے موجود تمام لائنیں مٹا کر (Ctrl+A پھر Delete) یہ نیا کوڈ Paste (Ctrl+V) کیجیے اور Save (Ctrl+S) دبا دیجیے۔
  3. اب اوپر دائیں جانب نیلے بٹن Deploy → Manage deployments → Edit (پنسل آئیکن) → Version: New version → Deploy پر کلک کر دیجیے۔
