**پتہ:** محلہ اسلم آباد، فیصل آباد روڈ، جھمرہ سٹی، ضلع فیصل آباد

## 1. ایپ کی اہم خصوصیات (Features)

1. **مکمل آف لائن سہولت (Offline-First PWA):** ایک بار کھلنے کے بعد یہ ایپ بغیر انٹرنیٹ کے بھی کھلتی ہے اور رسیدیں بناتی ہے۔ آف لائن رسید پر **"عارضی نمبر"** اور **"محفوظ (مقامی)"** لکھا آتا ہے، اور انٹرنیٹ آتے ہی سرور سے حتمی نمبر (`GM-YYYY-MM-NNNN`) مل جاتا ہے۔
2. **محفوظ گوگل لاگ ان (Google Identity Services):** صرف دو اجازت یافتہ اکاؤنٹس ایپ کھول سکتے ہیں:
   - `atiqgorayah@gmail.com` (مالک / Owner)
   - `qamarattari49@gmail.com` (امام و منتظم)  
   کسی بھی دوسرے اکاؤنٹ پر یہ پیغام آتا ہے: **"یہ اکاؤنٹ اجازت یافتہ نہیں ہے۔"**
3. **سرور سائیڈ پاسورڈ اور 30 منٹ سیشن:** رسید بنانے، ترمیم کرنے، حذف کرنے یا بیک اپ بحال کرنے کے لیے پاسورڈ لازمی ہے۔ سرور پر پاسورڈ کبھی سادہ شکل میں محفوظ نہیں ہوتا بلکہ رینڈم سالٹ (Salt) اور `100,000` بار `SHA-256` ہیش کے ساتھ محفوظ ہوتا ہے۔ 5 بار غلط پاسورڈ لکھنے پر اکاؤنٹ 15 منٹ کے لیے لاک ہو جاتا ہے۔
4. **ہر 15 سیکنڈ بعد خودکار سنک (`POLL_SECONDS = 15`):** جب ایپ اسکرین پر کھلی ہو تو ہر 15 سیکنڈ بعد نئی رسیدیں خودکار طور پر آ جاتی ہیں۔ ایپ بند یا بیک گراؤنڈ میں جانے پر پولنگ رک جاتی ہے۔
5. **رازداری کے ساتھ فوٹر:** ہر رسید کے نیچے صرف ای میل کے پہلے 5 حروف آتے ہیں (مثلاً `atiqg` یا `qamar`):  
   `بنانے والا: qamar، بتاریخ 20 اکتوبر 2026، وقت 09:30 PM`  
   پورا ای میل ایڈریس کبھی بھی اسکرین، پرنٹ، پی ڈی ایف یا CSV میں ظاہر نہیں ہوتا۔
6. **خودکار بیک اپ اور CSV ایکسپورٹ:** ہر رات 2:00 بجے (`Asia/Karachi`) گوگل شیٹ میں خودکار بیک اپ (`Backup_YYYY-MM-DD`) بنتا ہے اور پچھلے 30 بیک اپ محفوظ رہتے ہیں۔

7. **پاکستانی ڈیجی کھاتہ نظام (DigiKhata Khata Book & CashBook):**
   - **کھاتہ دار / پارٹیاں (Parties Ledger):** ڈونرز، سیمنٹ و اینٹ سپلائرز، کاریگروں، کرایہ داروں اور عملہ کے لیے باقاعدہ لیجر۔ 
   - **لینے ہیں 🟢 اور دینے ہیں 🔴:** ہر پارٹی کا بقایا بیلنس اور رننگ اسٹیٹمنٹ۔
   - **1-کلک واٹس ایپ سلپ و ریمائنڈر:** باوقار اردو واٹس ایپ میسج جس میں کل موصولی، کل ادائیگی اور موجودہ بقایا خودکار طور پر درج ہوتا ہے۔
   - **روزنامچہ کیش بک (DigiKhata Register):** فوری مدت فلٹرز (آج، کل، اس ہفتے، اس ماہ، مکمل ریکارڈ، کسٹم تاریخ رینج)، اور نقد کیش ان ہینڈ (Running Cash Balance)۔
   - **فنڈ وار کھاتہ جات اور اخراجات واؤچر:** تعمیراتی فنڈ، جنرل فنڈ، اور بجلی بلز وغیرہ کا تفصیلی آڈٹ ٹریل۔

## 2. گٹ ہب پیجز (GitHub Pages) پر اپڈیٹ اور ڈیپلائے کرنے کا طریقہ (ایک کمانڈ)

جب بھی آپ ایپ میں کوئی تبدیلی کریں یا نیا ورژن شائع کرنا چاہیں، اپنے کمپیوٹر کے ٹرمینل (Terminal / Command Prompt) میں پروجیکٹ فولڈر کھول کر صرف یہ **ایک کمانڈ** چلائیں:

```bash
npm run deploy
```

### یہ ایک کمانڈ کیا کرتی ہے؟
1. سب سے پہلے خودکار طور پر تمام ٹیسٹ (`npm run test`) چلاتی ہے تاکہ کسی غلطی کے ساتھ ایپ شائع نہ ہو۔
2. پھر `vite build` کے ذریعے پروڈکشن فائلز (`dist/` فولڈر) تیار کرتی ہے۔
3. آخر میں `gh-pages -d dist` کے ذریعے خودکار طور پر GitHub Pages پر نیا ورژن شائع کر دیتی ہے۔

### پہلی بار سیٹ اپ کے مراحل (اگر نئے کمپیوٹر پر چلائیں):
1. پروجیکٹ فولڈر میں `npm install` چلائیں۔
2. `npm run deploy` چلائیں۔
3. گٹ ہب ویب سائٹ پر اپنی ریپوزٹری کی **Settings -> Pages** میں جائیں اور **Branch** کے خانے میں `gh-pages` منتخب کر کے **Save** پر کلک کریں۔

## 3. گوگل ایپس اسکرپٹ (`apps-script/Code.gs`) سیٹ اپ کرنے کا طریقہ

1. اپنی گوگل شیٹ (`جامع مسجد غوثیہ رضویہ - رسید ریکارڈ`) کھولیں۔
2. اوپر مینو میں **Extensions -> Apps Script** پر کلک کریں۔
3. `apps-script/Code.gs` کا کوڈ وہاں پیسٹ کریں اور `apps-script/Tests.gs` کو دوسری فائل کے طور پر شامل کریں۔
4. ایڈیٹر میں اوپر فنکشن لسٹ سے ایک بار `installNightlyBackupTrigger` چلائیں تاکہ روزانہ رات 2 بجے بیک اپ بنتا رہے۔
5. اپنا رائٹر پاسورڈ سیٹ کرنے کے لیے ایڈیٹر کے اندر ایک عارضی فنکشن بنا کر `setWriterPassword("آپ_کا_پاسورڈ")` ایک بار چلائیں، اور چلانے کے بعد وہ لائن مٹا دیں۔
6. اوپر دائیں جانب **Deploy -> New deployment** پر کلک کریں:
   - **Type:** `Web app`
   - **Execute as:** `Me (atiqgorayah@gmail.com)`
   - **Who has access:** `Anyone`
7. **Deploy** پر کلک کریں اور ملنے والا **Web App URL** کاپی کر کے ایپ کی **ترتیبات (Settings)** اسکرین میں درج کر دیں۔
